# Tech Dose Daily — block theme

Custom WordPress block theme implementing the approved TechDoseDaily V1 design system.

- `theme.json`, `assets/css/tokens.css` and `assets/css/{core,article,archive,search,author,static,about-contact,newsletter-404}.css` are generated — run `npm run build` from the repo root (`06-WordPress`).
- `assets/css/*.min.css` and `assets/js/*.min.js` are generated by `npm run minify` (part of `npm run build`) and are what the site serves unless `SCRIPT_DEBUG` is on. Edit the readable files, never the `.min` ones.
- `assets/css/layout.css` is hand-written (responsive gutters, header/footer at in-between widths, menu drawer).
- `blocks/*` are server-rendered blocks (`block.json` + `render.php`) that print the approved component markup.
- `inc/` holds presentation modules: setup, assets, menus, template tags (labels, meta line, story card), shared components, article (`article.php`), section/archive feeds (`archive.php`), homepage modules (`home.php`), author page (`author.php`), search (`search.php`), static pages (`static.php`: header, sections, contents, related policies), page modules (`pages.php`: policy blocks, About, Contact form, Newsletter page, 404), block registration.
- Templates: `front-page.html`, `single.html`, `category.html`, `archive.html` (topic, story type, tag), `home.html` (Latest), `author.html`, `search.html`, `page.html` (policy layout), `page-short.html`, `page-about.html`, `page-contact.html`, `page-newsletter.html`, `404.html`, `index.html` (fallback).
- JS: `header.js`, `newsletter.js`, `pager.js` (Load more), `article.js` (share, TOC), `search.js` (filters, mobile sheet), `view-beacon.js` (Most Read), `contact.js` (contact form states), `editor-blocks.js` (editor UI for story and page blocks).
- **Requires the TechDoseDaily Core plugin** for the data model (sections, story types, topics, placements, Most Read, newsletter). Every call is guarded, so the theme still renders basic WordPress data without it.

Menus: Appearance → Menus → assign "Header sections" and the footer locations. Until assigned, the header and footer fall back to the real categories and pages that exist.
